## Limits

These authored synthetic samples qualify the identified issue scenarios, not a population-level memory success rate or broad M3/Q04–Q06 quality. Citation shape and resolution are exercised through the same parser and application query used by the app; no new native UI interaction or visual verification is claimed. Process continuity means orderly shutdown and a separate process, not crash recovery. No macOS 15 runtime test was performed locally.

The historical generic storage error remains unclassified despite the successful reruns. Its original evidence is preserved. A future recurrence should be investigated from its concrete stage and safe error code. The launcher retains an owned root when interrupted child exit is unknown; interrupt termination and crash recovery are outside these completed-run checks.
