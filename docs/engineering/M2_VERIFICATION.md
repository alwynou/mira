# M2 工具基础与 Markdown 验证记录

日期：2026-09-05。这是当前开发增量的证据，完整产品范围仍见 [MVP](../MVP.md)。

## 已实现

- 微软 SwiftStreamingMarkdown v0.7.0 对应 commit 固定在 Host。每 70 ms 合并正文快照，结束立即刷新；历史和流式使用相同 renderer。用户消息与助手回复使用不同稳定 ID。关闭图片加载与模型自编引用，外链只在用户点击后允许 HTTP(S)。
- 两类 Provider 的工具请求编码、增量参数组装、原始调用 ID 与 wire 名映射，完整批次后才交给 Runtime。孤立结果、重复 ID、语法损坏或大小超限在执行工具前失败。
- 每次模型请求有独立 Step / Attempt / Snapshot；工具参数、输出、调度时间和唯一回执持久化。下一请求保留完整同回合交换，下一用户回合不自动复用临时工具协议。
- 不可变工具注册表、输入 Schema 与宿主授权、并行批次和独占屏障、工具及回合取消 / 超时、步骤与 Token 预算、无进展终止。生产注册表为空，合成工具仅在测试中注入。
- 用户主动触发文本 / 工具能力探测；只发送固定合成提示，支持取消和失败状态，配置变化后不覆盖新配置。未在本次验证中调用付费模型服务。
- v2 迁移与严格备份恢复，包括旧 v1 数据、原备份保护、模型输出 / 工具调用配对和恢复幂等。

## 父代理复核修复

子任务使用用户指定的 GPT-5.6 Luna。父代理审阅并修复或要求修复了连续输入的 debounce 导致不刷新、用户与助手重复列表 ID、一次性 AsyncStream 生命周期、工具拒绝不能写回、旧 Step 重试可重复执行、Anthropic 空参数与终止顺序、探测伪阳性和取消状态等问题。

测试中还出现默认异步 sleep 闭包取消时的 `swift_task_dealloc` 崩溃。最小 `RuntimeClockTests` 可复现；改为 `RuntimeClock` 协议与具体系统实现后，最小测试和运行时测试通过。这里记录可复现观察与本项目修复，不推断所有 Swift 版本均受影响。

依赖清单复核发现 swift-markdown 0.7.3 要求 Swift 6.2。首次 Xcode 16.4 CI 已通过包测试，在应用阶段被后续修复提交替代取消；最终 CI 使用同一 macos-15 镜像提供的 Xcode 26.3。应用最低部署版本仍为 macOS 15。
